# Тридцять два — прототип платформи підготовки до НМТ з математики

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run dev
```

Відкрити адресу, яку покаже термінал (зазвичай http://localhost:5173).

## Збірка статичних файлів

```bash
npm run build      # результат у папці dist/
npm run preview    # локальний перегляд зібраної версії
```

Папку `dist/` можна залити на будь-який статичний хостинг — Netlify, Vercel, GitHub Pages, звичайний nginx.

## Структура

```
src/
  NMT_Platform_MVP.jsx   ← увесь інтерфейс, дані курсу і банк завдань
  main.jsx               ← точка входу + локальна заміна window.storage
  index.css              ← підключення Tailwind
```

## Про збереження прогресу

У середовищі Claude прогрес зберігається через `window.storage`. Локально цього API немає,
тому в `main.jsx` підставлено заміну на `localStorage` — прогрес живе в браузері користувача.
Коли дійде до справжнього бекенду, ці чотири методи (`get`, `set`, `delete`, `list`)
замінюються на виклики вашого API — решту коду чіпати не доведеться.

## Де що правити

| Що змінити | Де у файлі `NMT_Platform_MVP.jsx` |
|---|---|
| Кольори і шрифти | константи `C`, `DISPLAY`, `BODY` на початку |
| Теми і модулі курсу | масив `MODULES` |
| Банк завдань | масив `TASKS` |
| Стартові дані демо-учня | об'єкт `SEED` |
| Логіка зростання відсотка теми | функція `check` у компоненті `Practice` (+6 / −3) |
